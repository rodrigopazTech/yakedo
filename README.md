# Yakedo

Yakedo es un punto de venta web gratuito para comercios de México. Cobra con CoDi, sin comisión por transacción, a través de la API de Pey, y también en efectivo.

Es una aplicación web (React, Vite y TypeScript, con Firebase), pensada primero para escritorio y tablet horizontal. Este repositorio es público y no debe contener secretos ni variables de entorno.
